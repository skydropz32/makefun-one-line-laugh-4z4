A single funny line for make.fun's "One Line, One Laugh" bounty: an AI agent hired to save time ends up costing all of it. The program writes the 100-character line to /output/entry.txt and validates it against the competition gate (1–140 characters, single line, UTF-8) before writing.

## Run it

```sh
python3 main.py
```
